# Bamboo & Hemp Everyday Essentials – D2C E-Commerce Platform

## Project Structure

```
bamboo-hemp/
├── frontend/   → Next.js App (Port 3000)
├── backend/    → Express.js API (Port 5000)
├── PRD.md      → Product Requirements Document
└── README.md
```

## Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
# → http://localhost:3000
```

### Backend (when ready)
```bash
cd backend
npm install
npm run dev
# → http://localhost:5000
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 14 (App Router), React 18, CSS Modules |
| Backend | Node.js, Express.js, MongoDB (MVC) |
| Auth | JWT (backend), Context API (frontend) |

## Environment Variables

- Frontend: `frontend/.env.local`
- Backend: `backend/.env`
